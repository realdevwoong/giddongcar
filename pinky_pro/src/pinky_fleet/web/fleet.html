    P선택한 로봇의 초기 위치 도구 (RViz 2D Pose Estimate)
    G선택한 로봇의 목적지 도구 — 찍기만 하고, 카드의 ▶ 출발 또는 위의 ▶ 둘 다 출발로 보내요
    Esc좌표 입력 닫기 → 끌기 취소 → 도구 풀기 (Nav2 목표는 취소하지 않아요)

    ?이 도움말
    Shift + 놓기도구를 켜 둔 채로 계속 지정

    지도 읽는 법

    • 번호 원 ① ② = 로봇, 흰 쐐기 = 바라보는 방향, 점선 고리 = 선택한 로봇
    • 실선 = robot1 경로, 점선 = robot2 경로
    • 채운 깃발 = 진행 중인 목적지(아래 눈금 = 도착 방향), 빈 빨강 깃발과 ✕ = 실패한 목적지
    • 빨간 고리와 ! = 이동 실패 · 점선 빈 원 = 연결이 끊긴 로봇의 마지막 위치
    • 밝은 칸 = 바닥, 어두운 칸 = 벽, 청회색 = 미탐색 · 옅은 격자 = 0.5 m

    용어

    초기 위치
    RViz의 2D Pose Estimate와 같아요. AMCL에 /initialpose로 “로봇이 지금 여기 있어요”를 알려요.
    위치 찾기
    관제를 켜면 AMCL 전역 위치 찾기로 지도 전체에서 스스로 위치를 찾아요. 기본(auto_spin:=true)은 켜자마자 제자리에서 한 바퀴 돌고 0 속도로 멈춰요. auto_spin:=false면 가만히 라이다로만 찾아요. 확인되기 전에는 지도에 그리지 않아요. 못 찾으면 ⟳ 돌면서 찾기 — 로봇 주변을 보고 누르면 제자리에서 천천히 한 바퀴 돌고 0 속도로 멈춰요(■ 이동 취소로도 멈춤). 확인된 위치가 틀렸으면 초기 위치를 찍어 고쳐요.
    목적지
    RViz의 Nav2 Goal과 같아요. navigate_to_pose 목표를 보내요.
    복구
    막혔을 때 Nav2가 스스로 하는 후진·제자리 회전·기다리기.
    이동 취소
    Nav2 목표 취소예요. 비상 정지가 아니에요. pinky_bringup은 마지막 cmd_vel을 계속 따르니, 키보드(teleop)로 몰았다면 그 터미널에서 0 속도를 한 번 보내세요.
    램프
    대시보드가 목표 상태에 맞춰 로봇 램프에 보낸 명령이에요(예: 이동 중 파랑 깜빡임, 도착 초록, 실패 빨강 빠른 깜빡임). ✓ = 램프 노드가 받았어요. 실제 불빛은 로봇에서 확인해요.
    ✕ 램프 응답 없음 = 램프 노드(set_lamp)가 없거나, 3초 안에 답이 없거나, 거부했어요. 대시보드가 알아서 다시 보내요. pinky_bringup은 램프 노드를 켜 주지 않으니 로봇에서 따로 실행하세요 (시뮬은 sim.launch.py가 켜요). 대시보드가 2초마다 다시 보내요.
    알림 끄기
    머리줄·카드의 알림만 숨겨요. 로봇에는 아무것도 보내지 않아요.
    방향
    0° = +x(오른쪽), 반시계 방향이 +.
